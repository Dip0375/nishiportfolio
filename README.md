# Nishita Anna Pingua — Portfolio

Personal portfolio website of Nishita Anna Pingua, HR Executive (Talent Acquisition · HR Operations · HRIS), Kolkata.

Live site: https://dip0375.github.io/nishiportfolio/

## Files
- `index.html` — the whole site (HTML, CSS and JavaScript in one file)
- `images/` — logo, icons, photos and social share image

## Update content
Edit the text directly in `index.html`. To change a photo, replace the file in `images/` with one of the same name.

## Preview locally
Open `index.html` in any browser.
